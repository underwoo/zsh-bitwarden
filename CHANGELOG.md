# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release
- Bitwarden CLI (`bw`) support
- Vault unlock/lock management (`bwu`, `bwl`)
- Password retrieval with auto-clear clipboard (`bwp`)
- Username retrieval (`bwun`)
- TOTP code generation (`bwt`)
- Item listing and search (`bwls`)
- Full item details retrieval (`bwget`)
- Password generation (`bwgen`)
- Status checking aliases (`bws`, `bwsy`)
- Tab completion for `bw` commands
- Security: 20-second auto-clear clipboard
- Comprehensive documentation and examples

## [1.0.0] - 2026-07-07

### Added
- Initial public release
- Full Bitwarden CLI integration
- Oh My Zsh plugin framework
